Key security notes
Your full API key is shown once at creation — store it securely.
Keys are stored as SHA-256 hashes; we cannot recover the raw key.
Revoke compromised keys immediately — revocation is instant.
API Reference
REST endpoints · authentication · examples
Authentication
Every request must include your API key as a Bearer token.
Authorization: Bearer ck_live_your_key_here
Endpoints
POST/v1/registerCreate account, get API key. No auth required.
POST/v1/encryptAES-256-GCM encrypt. Body: {"plaintext":"…"}
POST/v1/decryptAES-256-GCM decrypt. Body: {"ciphertext":"…","nonce":"…"}
GET/v1/usageDaily usage stats and 30-day history.
GET/v1/keysList all API keys for your account.
POST/v1/keysCreate additional API key. Body: {"label":"…"}
POST/v1/keys/revokeRevoke a key by prefix.
GET/v1/statusEncryption server health check.
curl examples
# Register curl -X POST http://localhost:8000/v1/register \ -H "Content-Type: application/json" \ -d '{"email":"user@example.com","name":"Alice"}' # Encrypt curl -X POST http://localhost:8000/v1/encrypt \ -H "Authorization: Bearer ck_live_..." \ -H "Content-Type: application/json" \ -d '{"plaintext":"hello world"}' # Decrypt curl -X POST http://localhost:8000/v1/decrypt \ -H "Authorization: Bearer ck_live_..." \ -H "Content-Type: application/json" \ -d '{"ciphertext":"…","nonce":"…"}' # Usage stats curl http://localhost:8000/v1/usage \ -H "Authorization: Bearer ck_live_..."
